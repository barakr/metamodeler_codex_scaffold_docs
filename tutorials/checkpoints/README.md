# Tutorial checkpoints

This folder can hold optional saved artifacts per tutorial run.

Suggested convention:
- `tutorials/checkpoints/t1/` for Tutorial 1 outputs
- `tutorials/checkpoints/t2/` for Tutorial 2 outputs
- ...
- `tutorials/checkpoints/t9/` for Tutorial 9 outputs

The tutorial track is designed to be mostly standalone. If you run serially,
you can reuse artifacts from earlier tutorials instead of regenerating them.
